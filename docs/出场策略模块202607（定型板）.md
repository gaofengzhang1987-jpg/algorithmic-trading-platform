## 三、初始止损（按买点类型）

入场时从预计算结构表中快照锁定四个参考值，然后计算初始防线。

### 3.1 快照值获取

| 属性 | 获取方式 | 含义 |
|------|---------|------|
| `entry_bi_low_1buy` | 入场日期前最近向下笔的底分型 low，fallback 到笔 low | 一买底分型低点 |
| `entry_bi_low_2buy` | 入场日期前最后一个底分型 low | 二买底分型低点 |
| `entry_bi_low_3buy` | 同二买（入场时的最近底分型） | 三买底分型低点 |
| `entry_pivot_gg` | 入场日期前最后一个已走完（`edt <= 入场日`）的上涨中枢 GG | 三买中枢 GG |

> 结构快照只取 `edt` 不晚于入场日的笔/中枢，禁止使用尚未走完结构的未来极值。

### 3.2 止损计算公式

| 买点 | 公式 | Fallback 链 |
|------|------|-------------|
| 一买 | `entry_bi_low_1buy × 0.96` | → `entry_bi_low_2buy → 入场价 × 0.92` |
| 二买 | `max(entry_bi_low_1buy, entry_bi_low_2buy) × 0.92` | → `入场价 × 0.92` |
| 三买 | `max(entry_pivot_gg, entry_bi_low_3buy) × 0.95` | → `入场价 × 0.95` |
| 未知 | `入场价 × 0.92` | — |

### 3.3 折扣设计理念

- **一买 ×0.96**：一买是抄底点，底分型低点 = 转折失败的临界点。给 4% 容忍避免误杀
- **二买 ×0.92**：回踩确认后再破位 → 结构失效概率高，给 8% 容忍
- **三买 ×0.95**：中枢上方回抽，GG 被穿 → 中枢破坏，给 5% 容忍

## 四、防线推进（在持仓期间，每 bar 更新）

**核心原则**：防线只上移（`defense = max(defense, new_value)`），不下移。

**未来数据约束**：任何用于推进防线/触发出场判断的结构事件必须已完整走完（`edt <= 当前 bar`），未结束的中枢 GG、向下笔低点不得参与计算。

### 4.1 一买入场

| 结构事件 | 新防线 | 
|----------|-------|
| 入场后形成新的向下笔底分型 | 底分型 low（高于当前防线时生效） |
| 入场后形成新的上涨中枢 | 中枢 GG（高于当前防线时生效） |

### 4.2 二买入场

| 结构事件 | 新防线 |
|----------|-------|
| 入场后形成新的上涨中枢 | 中枢 GG |

### 4.3 三买入场

三买已处于趋势最高结构位置，不再推进防线。始终持有初始止损。

## 五、出场路径（逐 bar 扫描，取最早触发）

### 5.1 硬出场（任何仓位状态下生效）

| 优先级 | 条件 | 操作 | 出场价 |
|:---:|------|------|------|
| 1 | `收盘价 ≤ 防线` | 全清 | 当 bar 收盘价 |
| 2 | `收盘价 < 入场后最新上涨中枢 GG` | 全清 | 当 bar 收盘价 |
| 5 | `bar_date ≥ 卖点信号目标日` | 全清/剩余 | 目标日开盘价 |

> V 型暴跌附加保护：GG < 收盘价 × 1.5（防止 GG 为异常极大值时误触发）

### 5.2 状态依赖出场

```
                    ┌──────────┐
                    │   FULL   │  满仓 1.0
                    │  入场    │
                    └────┬─────┘
         顶分型+背驰+创新高│
                         ▼
                    ┌──────────┐
                    │   HALF   │  半仓 0.5
                    │          │
          ┌─────────┤          ├──────────┐
          │         └──────────┘          │
    突破高点接回     二卖确认 / 30天超时    硬出场1/2
     → FULL          → EMPTY              → EMPTY
```

### 5.3 顶分型减半仓 — 三条合并

1. **顶分型**：当 bar 的 `fx_b_mark == "顶分型"`
2. **创新高**：`bar.high > 前一个向上笔的高点`
3. **背驰**：三级 fallback（见 §5.4）

→ 记录顶分型高点（接回用），仓位降为 50%。

### 5.4 背驰判断 — 三级 fallback

```
优先级 1: 30 分钟 struct_cache → 最近两个向上笔 → 查表比 power（O(1)）
   ↓ 无 30m 缓存
优先级 2: 日线 struct_cache → 最近两个向上笔 → 查表比 power（O(1)）
   ↓ 无日线结构表
优先级 3: 跳过背驰要求（仅顶分型触发）
```

背驰成立条件：`bi[-1].power < bi[-2].power`（当前向上笔力度 < 前一同向笔力度）

### 5.5 二卖确认

半仓后追踪 `max(high_since_half_cut)`：
- 若始终 < 顶分型高点（反抽不破）
- 且再次出现顶分型
→ 剩余半仓清仓

### 5.6 接回（Buyback）

`bar.high > 顶分型高点` → 恢复全仓 + 重绑防线（`rebind_defense`）

重绑后防线按最新结构重新计算，但不下移（保留 `max(old_defense, new_defense)`）。

### 5.7 半仓超时

30 个交易日仍未接回/二卖确认 → 剩余半仓清仓。

## 六、数据预计算（precompute_structure.py）

中枢识别算法：滑动窗口 3 笔重叠区间检测 → 离开段方向判定中枢方向。

输出每只股票 ~100 行（每行一根 BI），包含笔方向、高低点、力度、分型标记、中枢归属信息。

性能：单只股票 ~0.3 秒。5000 只股票全量预计算 ~25 分钟（单线程）。

### 6.1 30 分钟 struct_cache 预计算

脚本：`tmp_out/build_struct_cache_30m_full.py`
数据源：`data/min30/`（5,745 只，15,690 bars/只）
输出：`data/struct_cache_30m/{code}.parquet`（14字段，全量 CZSC bi + 分型 + 中枢 + fx_b_has_zs）

构建方式：8 workers 多进程，完整运行 CZSC（max_bi_num=50）后提取 bi_list 与中枢。
性能：~1.9 只/s（8 workers），全量 ~50 分钟。
输出格式：与日线 `data/struct_cache/` 完全一致的 13 字段格式（direction, high, low, sdt, edt, power, fx_b_mark, fx_b_low, fx_a_mark, pivot_dir, pivot_gg, pivot_zd, pivot_zg）。

现场验证结果：5,741/5,745 缓存构建成功（4 只缺失），格式与日线一致，背驰判断结果正确。

## 八、附录：中枢 GG 计算算法

```
1. 从 bi_list[i] 开始，取 bi_i, bi_{i+1}, bi_{i+2}
2. overlap_high = min(三笔的高点), overlap_low = max(三笔的低点)
3. 如果 overlap_high > overlap_low → 中枢形成
4. 向后延伸：bi_{i+3} 与区间 [overlap_low, overlap_high] 有交集 → 纳入
5. GG = max(参与中枢的所有笔的 high)
6. 方向 = 离开段方向（离开段 Up → 上涨中枢；离开段 Down → 下跌中枢）
```
