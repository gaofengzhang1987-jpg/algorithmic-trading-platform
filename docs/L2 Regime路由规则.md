## 一、Regime 检测

自动检测（`run_zones.py`），基于上证综指 MA 状态：

| Regime | 条件 |
|--------|------|
| BULL | close > MA20 > MA60，MA20 斜率 > 0 |
| BEAR | close < MA20 < MA60，MA20 斜率 < 0 |
| CHOP | 以上之外 |

可通过 `sys.argv[2]` 手动覆盖。

## 四、直通规则

以下股票跳过 L2 阈值——照常打分，不淘汰：

- **B+ 通过**：`verify_buy_type(code, bt)` 返回 True（一买不算，仅二买/三买）
- **三级联立**：周线 + 日线 + 30min 同一买点类型同时共振

直通由 `run_zones.py` 计算 `bplus_codes` 集合传入 L2。

## 五、CZSC 维度定义（EntryFilter 内部）

所有维度使用 CZSC 的 `bi_list` 和 pivots 计算：

| 维度 | 计算逻辑 |
|------|----------|
| 笔数 | 中枢前向上笔计数 |
| 核心验证 | 一买=背驰力度比 | 二买=回踩深度 | 三买=ZG 距离 |
| 底分型 | fx_list 最近底分型的 K 线结构+量能 |
| 量比 | 买点当日量 / 20日均量 |
| MACD | 最近金叉距离 |
| 中枢/距离 | 下跌中枢下沿或距最后向下笔低点 |
| 区间位置 | 60 日高低区间底部位置 |
| 波动压缩 | ATR14/ATR50 |
| 时间消化 | 距最后向下笔完成天数 |
| 相对强度 | 个股 20 日超额 vs 上证 |
| 回抽深度 | (ZG-入场价)/ZG |
| ZG站稳天数 | 收盘 > ZG 连续天数 |
| ATR扩张比 | 突破后 ATR / 中枢内 ATR |
| 突破量持续性 | 突破后量 / 中枢内均量 |
| 前低防守 | (入场价-一买低点)/一买低点 |
| 反弹力度 | 一买低→反弹高涨幅 |
| 二次放量 | 信号日量/回踩期均量 |
| MA防守 | MA20/MA60 位置 |
| MA排列强度 | MA5>MA20>MA60 三线向上 |
| 底部放量 | 信号日+前2日量/20日均量 |
