## 一、Regime 检测

五维牛熊评分制（`regime_detector.detect()`），对上证综指（000001）每日计算 0–100 的 Bull Score，按阈值切分三区。

### 维度与权重

| # | 维度 | 满分 | 核心判定逻辑 |
|---|------|:---:|------|
| 1 | 均线排列 | 25 | MA5/10/20/60/120 多头/空头配对数，4 对全多=25，全空=0 |
| 2 | 价格位置 | 25 | close vs MA60/MA120/MA250 梯度，年线上方=25，季线下方=0 |
| 3 | ADX 趋势强度 | 20 | ADX(14) + DI 方向，ADX≥30 +DI>−DI=20，ADX<20=10 |
| 4 | 量价关系 | 15 | 5 日均量 vs 20 日均量 + 5 日涨跌，放量上涨=15，放量下跌=0 |
| 5 | 指数协同 | 15 | 000001 + 000852 同步站上 MA60=15，全破=0 |

### 分类阈值

| Bull Score | Regime |
|:----------:|--------|
| ≥ 70 | BULL |
| 30–69 | CHOP |
| < 30 | BEAR |

### 防抖动

Regime 仅在 Bull Score 连续 **3 个交易日**保持在新区间后才正式切换。状态持久化至 `tmp_out/regime_state.json`。

可通过 `python3 run_zones.py <top_n> BULL|BEAR|CHOP` 手动覆盖 regime。

## 四、直通规则

以下股票跳过 L2 阈值——照常打分，不淘汰：

- **B+ 通过**：`verify_buy_type(code, bt)` 返回 True（一买不算，仅二买/三买）
- **三级联立**：周线 + 日线 + 30min 同一买点类型同时共振

直通由 `run_zones.py` 计算 `bplus_codes` 集合传入 L2。

> **2026-08-07 更新**：`check_resonance` 已改为严格时间对齐（与 zone2_regime 内部一致）：
> - 数据新鲜度：末 bar 距今天 ≤ 7 自然日
> - 周线 ↔ 日线：≤ 5 自然日
> - 30分钟 ↔ 日线：≤ 2 自然日

## 五、CZSC 维度定义（EntryFilter 内部）

所有维度使用 CZSC 的 `bi_list` 和 pivots 计算：

| 维度 | 计算逻辑 |
|------|----------|
| 笔数 | 中枢前向上笔计数 |
| 核心验证 | 一买=背驰力度比 | 二买=回踩深度 | 三买=ZG 距离 |
| 底分型 | fx_list 最近底分型的 K 线结构+量能 |
| 量比 | 买点当日量 / 20日均量 |
| MACD | 最近金叉距离 |
| 中枢/距离 | 下跌中枢下沿或距最后向下笔低点 |
| 区间位置 | 60 日高低区间底部位置 |
| 波动压缩 | ATR14/ATR50 |
| 时间消化 | 距最后向下笔完成天数 |
| 相对强度 | 个股 20 日超额 vs 上证 |
| 回抽深度 | (ZG-入场价)/ZG |
| ZG站稳天数 | 收盘 > ZG 连续天数 |
| ATR扩张比 | 突破后 ATR / 中枢内 ATR |
| 突破量持续性 | 突破后量 / 中枢内均量 |
| 前低防守 | (入场价-一买低点)/一买低点 |
| 反弹力度 | 一买低→反弹高涨幅 |
| 二次放量 | 信号日量/回踩期均量 |
| MA防守 | MA20/MA60 位置 |
| MA排列强度 | MA5>MA20>MA60 三线向上 |
| 底部放量 | 信号日+前2日量/20日均量 |

## 六、共振新鲜度防护（2026-07-31 新增）

为防止陈旧信号数据导致误判三级联立/周日共振，加入四层防护：

### 1. 数据文件新鲜度（`zone2_regime.py` `_check_weekly_resonance` / `_check_30min_resonance`）

周线/30min 信号文件的**最后一条 bar** 距今天 > 7 自然日时，返回 `None` → 跳过该级别的共振判定。

### 2. 信号事件新鲜度（`zone2_regime.py` `run()`）

L1 最新信号日距今天 > 10 自然日时，**跳过该代码的共振判定**（`continue`）。

### 3. 共振日期对齐 L1 信号日期（`zone2_regime.py` `run()`）

共振判定使用 L1 的 `最新日期` 而非 `_detect_changes` 的变化日。三级联立回答的是"当前 L1 报告的活跃买点在三个级别是否同时成立"，而非"两周前的信号变化是否曾有过共振"。

### 4. 共振时间对齐（`zone2_regime.py` `run()`）

对 L1 信号日和共振 bar 的日历差做窗口检查（A 方案，精确对齐）：

| 级别 | 窗口 |
|------|:---:|
| 周线 ↔ 日线 | ≤ 5 自然日 |
| 30分钟 ↔ 日线 | ≤ 2 自然日 |

30分钟 idxmin 对齐到信号日 `09:30`（而非午夜），避免错误选到前一日 15:00 的 bar。

### 5. 陈旧信号文件清理（`signal_chunk.py`）

CZSC 信号重生前先删除旧信号文件。若 CZSC 返回空，不残留旧文件，`failed` 计数器 +1。

### 6. B+ 结构验证（`verify_buy_type.py`）

B+ 结构验证**不需要**显式时间对齐。它分析 struct_cache 中的最新笔序列（`bis.iloc[-3:]`），结构特征是累积的，用更完整的当前数据验证比截断到历史信号日期更准确。
