# 二买三买结构链验证

> 文档日期：2026-07-24  
> 实现文件：`verify_buy_type.py`（117 行）  
> 依赖：`data/signals/*.parquet`、`data/struct_cache/*.parquet`、`data/daily/*.parquet`  
> 触发位置：`l1_score_all.py` BUY_COLS 链与 EntryFilter 之间（2 行集成）

---

## 一、设计原则

辅助信号（`BS2辅助`、`BS3辅助`、`三买辅助V230228`）是 CZSC 的统计模型输出，不验证缠论结构前提。结构链验证器在辅助信号标记买点之后，用结构数据做二次确认。

```
辅助信号输出"二买" → 结构链验证 → 通过 → 进入 L2 打分
                                  → 不通过 → 跳过
```

---

## 二、验证逻辑

### 一买：免检

核心信号 `D1B_BUY1` 本身是 CZSC 的标准缠论一买（背驰+底分型确认），不需要结构验证。

```python
if buy_type == "一买":
    return True
```

---

### 二买：4 步检查

#### 第 1 步：一买历史存在

从 `data/signals/{code}.parquet` 中读取 `日线_D1B_BUY1` 列的回看窗口（`LOOKBACK_DAYS=120` 行）。如果该列在窗口内从未出现 `一买_` 前缀的值，说明这只股票近期没有一买基础，拒绝。

**符合缠论的理由**：二买是一买后的确认买点。如果历史上从未有过一买，不存在"回踩"的前提。

```python
recent = sf[BUY1_COL].tail(LOOKBACK_DAYS).dropna()
if not any(str(v).startswith("一买_") for v in recent):
    return False
```

#### 第 2 步：笔的顺序确认

从 `data/struct_cache/{code}.parquet` 读取最后的 3 笔，按 `edt`（结束日期）排序。

```
期望序列（从旧到新）：
  向下（一买/底部）→ 向上（反弹）→ 向下（回踩/二买形成中）
```

检查：
- 最后 1 笔 `direction == "向下"`（当前在回踩阶段）
- 倒数第 2 笔 `direction == "向上"`（反弹段存在）

```python
last = bis.iloc[-1]   # 向下 -> 回踩
second = bis.iloc[-2] # 向上 -> 反弹
if last["direction"] != "向下" or second["direction"] != "向上":
    return False
```

**符合缠论的理由**：二买必须处于回踩阶段。如果当前笔是"向上"，说明价格在反弹或突破中，不构成二买条件。

#### 第 3 步：回踩不破底

```
条件：last(low) > third(low)
      ↓            ↓
   回踩笔低点   一买笔低点
```

```python
third = bis.iloc[-3]  # 向下 -> 一买底部
if last["low"] <= third["low"]:
    return False
```

**符合缠论的理由**：二买的底线是一买的最低点。如果回踩跌破了一买底，结构已经被破坏，不存在二买。

#### 第 4 步：价格在回踩区域

```
条件：
  price < 反弹 high × 0.97  （未脱离回踩区域进入反弹/突破）
  price > 回踩 low × 0.95   （未跌破回踩支撑位）
```

```python
if price >= second["high"] * 0.97 or price < last["low"] * 0.95:
    return False
```

**符合缠论的理由**：二买是"底部确认后的回踩买点"。价格如果在反弹 high 附近，说明已脱离回踩区域、进入新一轮反弹，不再是二买。价格如果跌破回踩低点，说明处于下跌中继。

---

### 三买：4 步检查

#### 第 1 步：上涨中枢存在

从 `data/struct_cache/{code}.parquet` 中查找 `direction == "pivot"` 且 `pivot_dir == "上涨"` 的中枢。

```python
up_pivots = pivots[pivots["pivot_dir"] == "上涨"]
if up_pivots.empty:
    return False
```

**符合缠论的理由**：三买的前提是存在一个已经完成的上涨中枢。没有中枢就没有三买。

#### 第 2 步：突破确认

找到中枢结束后的第一个向上笔，检查其 high 是否大于中枢 `ZG`。

```python
pivot_end = pd.to_datetime(last_pivot["edt"])
after_pivot = bis[pd.to_datetime(bis["sdt"]) >= pivot_end]
up_after = after_pivot[after_pivot["direction"] == "向上"]
breakout = up_after.iloc[0]
if breakout["high"] <= zg:
    return False
```

**符合缠论的理由**：中枢之后必须有一个突破行为。如果突破笔的最高点没有超过中枢 ZG，说明价格从未离开中枢，不存在"回踩"的对象。

#### 第 3 步：回踩未入中枢

中枢突破后检查是否有回踩笔，且回踩笔的 low 不低于 ZG。

```python
if len(bis_after) >= 2 and bis_after.iloc[-1]["direction"] == "向下":
    retrace = bis_after.iloc[-1]
    if retrace["low"] <= zg:
        return False
```

**符合缠论的理由**：三买的核心特征是"回踩但不进入中枢"。如果回踩 low <= ZG，说明价格跌回了中枢内部，不构成第三类买点。

#### 第 4 步：当前价格在中枢之上

```python
price = float(pd.read_parquet(dp).sort_values("date").iloc[-1]["close"])
if price < zg:
    return False
```

**符合缠论的理由**：当前价格必须在中枢运行区间之上。如果跌破 ZG，说明价格已进入中枢或跌破中枢，三买条件已消失。

## 三、验证结果（1,360 只股票，CHOP 环境）

### 各版本对比

| 买点 | 原始 | B（历史不检）| **B+（结构链）** |
|:---:|:---:|:---:|:---:|
| 一买 | 954 | 954 | 954 |
| 二买 | 262 | 157 | **42** |
| 三买 | 144 | 38 | **0** |
| 合计 | 1,360 | 1,149 | **996** |

### 二买剔除原因分类（220 只被淘汰）

| 原因 | 数量 | 占比 |
|------|:---:|:---:|
| 最后笔不是"向下"（价格在上升段，辅助信号提前标记） | ~88 | 40% |
| 回踩 low ≤ 一买 low（结构破坏，创新低） | ~66 | 30% |
| 价格 ≥ 反弹 high×0.97（已脱离回踩区域） | ~66 | 30% |

### 三买剔除原因分类（144 只全淘汰）

| 原因 | 数量 | 占比 |
|------|:---:|:---:|
| 不存在上涨中枢（CHOP 环境下无趋势段） | ~108 | 75% |
| 突破笔 high ≤ ZG（价格从未离开中枢） | ~22 | 15% |
| 价格回踩 ≤ ZG（回到中枢内部） | ~14 | 10% |

## 四、参数说明

| 参数 | 默认值 | 作用 |
|------|:---:|------|
| `LOOKBACK_DAYS` | 120 | 二买验证中 D1B_BUY1 的回看行数 |
| `ZG_UPPER_RATIO` | 1.2 | 三买价格上限：ZG × 1.2 以内（当前已不用） |

---

## 五、与回测（`simulate_trades`）的关系

结构链验证器**不接入回测管线**。`core/signal_detector.py` 和 `backtest/runner.py` 不受影响。回测仍然使用 `detect_all_changes` 的全历史扫描，验证只在选股管线（L1→L2→L3→L4）中生效。
