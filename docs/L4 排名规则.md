# L4 排名规则

> 更新时间：2026-07-24  
> 实现文件：`l4_ranker.py` → `L4Ranker` + `zone4_regime.py` → `run()`  
> 管线位置：`run_zones.py` L3→L4

---

## 一、排名管道

```
L3 输出 → 行业 Cull → L2 买点内归一化 → RPS 加权 → 分区排名 → 去重 → top_n
```

---

## 二、行业 Cull

sector RPS < 40 的股票淘汰，不进入后续排名。

---

## 三、L2 买点内归一化

同一买点类型（一买/二买/三买）内部将 L2 总分压缩到 0-1：

$$nL2 = \frac{score - min(同组)}{max(同组) - min(同组)}$$

消除三买天然高分碾压一买二买的问题。

---

## 四、RPS 加权合成

$$composite = 0.40 \cdot nL2 + 0.40 \cdot nStockRPS + 0.20 \cdot nSectorRPS$$

三个维度均做全局归一化后加权。

---

## 五、分区排名

| 排序优先级 | 说明 |
|-----------|------|
| 1. 买点类型 | 三买 → 二买 → 一买 |
| 2. composite | 降序 |
| 3. global_rank | 跨区连续编号 |

每组内部按 composite 降序排列。

---

## 六、去重

同一代码保留 composite 最高的一行（按 `code` 去重，`keep="first"`），避免同一股票占多个排名位。

---

## 七、输出

| 列 | 含义 |
|------|------|
| `code` | 股票代码 |
| `composite` | 综合评分 |
| `zone_rank` | 买点类型内排名 |
| `global_rank` | 全局排名 |
| `现价` / `买点类型` | 从 L3 继承 |
