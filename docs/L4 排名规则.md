# L4 排名规则

> 更新时间：2026-08-06  
> 实现文件：`l4_ranker.py` → `L4Ranker` + `zone4_regime.py` → `run()`  
> 管线位置：`run_zones.py` L3→L4

---

## 一、排名管道

```
L3 输出 → 行业 Cull → L2 买点内归一化 → RPS & Qlib 加权 → 全局排名 → 去重 → top_n
```

---

## 二、行业 Cull

sector RPS < 40 的股票淘汰，不进入后续排名。

---

## 三、L2 买点内归一化

同一买点类型（一买/二买/三买）内部将 L2 总分压缩到 0-1：

$$nL2 = \frac{score - min(同组)}{max(同组) - min(同组)}$$

消除三买天然高分碾压一买二买的问题。

---

## 四、RPS 加权合成

$$composite = 0.50 \cdot nL2 + 0.25 \cdot nStockRPS + 0.25 \cdot nQlib$$

| 维度 | 权重 | 归一化 |
|------|------|--------|
| `nL2` | 0.50 | 买点类型内 min-max |
| `nStockRPS` | 0.25 | 全局 min-max |
| `nQlib` | 0.25 | 全局 min-max；信号质量分类器预测买点信号盈利概率的 rank percentile（`qlib_ml.SignalQlibPredictor`，AUC=0.589） |

三个维度均做归一化后加权。sector_rps 仅参与硬 cull（<40 淘汰），不进入 composite。

---

## 五、排名

`global_rank` 按 composite 降序全局排列（不分区）。
`zone_rank` 为参考列，在各买点类型内部按 composite 降序编号。

---

## 六、去重

去重前先按 三买 > 二买 > 一买 排序，保证同一代码保留买点类型优先级最高的行。
同一代码保留 composite 最高的一行（按 `code` 去重，`keep="first"`），避免同一股票占多个排名位。

---

## 七、三级联立保留

三级联立（`[周_日_30m_联立]`）股票：
- 跳过 sector cull（sector_rps 强制设为 100）
- 不受 top_n 截断限制——被截断后自动找回
- 保留 L4Ranker.rank() 原始 composite / global_rank / zone_rank 评分，仅附加 tag="三级联立豁免"

## 八、输出

| 列 | 含义 |
|------|------|
| `code` | 股票代码 |
| `composite` | 综合评分 |
| `zone_rank` | 买点类型内排名 |
| `global_rank` | 全局排名 |
| `现价` / `买点类型` | 从 L3 继承 |
