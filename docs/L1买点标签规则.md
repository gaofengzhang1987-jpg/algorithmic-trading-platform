# L1 买点标签规则

> 更新时间：2026-07-24  
> 实现文件：`verify_buy_type.py` → `get_buy_label(code, buy_type)`  
> 管线位置：`zone1_deposition.py` → L1 拆分 buy_type 后逐行打标签

---

## 一、标签格式

```
{买点类型}_{结构状态}[_{趋势方向}]
```

三段式，趋势方向仅对 B+ 未通过的股票附加。

---

## 二、一买标签（524 只）

来自 CZSC `D1B_BUY1` 信号，不经过 B+ 验证，不细分。

| 标签 | 条件 |
|------|------|
| `一买` | D1B_BUY1 列末行值含 `一买_` |

## 三、二买标签（158 只）

### B+ 通过（不加趋势）

| 标签 | 条件 | 数量 |
|------|------|:---:|
| `二买_标准` | 回撤 30-70%，底分型存在，DOWN-UP-DOWN | — |
| `二买_类` | 回撤 > 70% 或无底分型 | — |
| `二买_浅回踩` | 回撤 < 30%，底分型存在 | — |

判定规则：
```
回撤深度 = (反弹high − 回踩low) ÷ (反弹high − 一买low)
  < 30% + 底分型 → 浅回踩
  30-70% + 底分型 → 标准
  > 70% 或无底分型 → 类
```

### B+ 未通过（加趋势）

| 标签 | 条件 | 数量 |
|------|------|:---:|
| `二买_无基础_{趋势}` | 120 日内无 D1B_BUY1 一买信号 | — |
| `二买_未企稳_{趋势}` | 笔序非 DOWN-UP-DOWN 或价格未企稳 | — |
| `二买_创新低_{趋势}` | 回踩低点 ≤ 一买低点 | — |

趋势判定（`_get_trend`）：close>MA20>MA60 且 MA20 斜率>0→多头；close<MA20<MA60 且斜率<0→空头；其余→震荡。

### 验证步骤（`_verify_second_buy`）

1. 检查 120 日内 D1B_BUY1 是否存在 `一买_` 信号
2. 从 BS2 列找到最近一次 `非二买→二买` 的触发日期
3. 读 struct_cache，筛选 bi 行，按 `sdt` 排序
4. 若信号日期 ≤ 30 天，截断 bi 至 `edt ≤ signal_date`
5. 检查末 3 笔方向：`DOWN-UP-DOWN`
6. 检查创新低：`回踩 low ≤ 一买 low`
7. 价格检查：`当前价 < 回踩 low × 0.95`
8. 计算回撤深度 + 底分型判定细分标签

## 四、三买标签（23 只）

### B+ 通过（不加趋势，136 只）

| 标签 | 条件 | 数量 |
|------|------|:---:|
| `三买_标准` | 突破幅度 > 5% ZG + 底分型 | — |
| `三买_弱突破` | 突破幅度 ≤ 5% ZG + 底分型 | — |
| `三买_类` | 底分型缺失 | — |

突破幅度 = `(突破笔 high − ZG) ÷ ZG`（2026-07-24 从 `ZG × 5%` 改为百分比）

### B+ 未通过（加趋势，135 只）

| 标签 | 条件 | 数量 |
|------|------|:---:|
| `三买_无中枢基础_{趋势}` | struct_cache 无上涨 pivot | — |
| `三买_未突破中枢_{趋势}` | 所有 UP bi 的 high ≤ ZG | — |
| `三买_回踩进中枢_{趋势}` | 突破后回踩 low ≤ ZG | — |
| `三买_跌破中枢_{趋势}` | 当前价 < ZG | — |

### 验证步骤（`_verify_third_buy`）

1. 读 struct_cache，找最后一个上涨 pivot，取 ZG
2. 筛选 pivot end 后的 bi，找**所有** UP bi 中首次 `high > ZG` 的
3. 检查回踩是否跌回中枢（`retrace low ≤ ZG`）
4. 检查当前价是否跌破 ZG
5. 判定：突破幅度 + 底分型 + retrace 位置 → 标签

## 五、共振标识

附加到 `买点类型` 标签尾部，不影响 B+ 通过状态：

| 标识 | 条件 |
|------|------|
| ` [周_日_共振]` | 周线+日线同一买点类型同时存在 |
| ` [周_日_30m_联立]` | 周线+日线+30分钟三级同时共振 |

三级联立自动加入 B+ 直通队列（由 `check_resonance()` 实现，不修改标签文字）。

---

## 六、命名原则

- 结构优先：标签描述"结构完整吗？哪一步出问题？"
- 趋势仅用于失败：B+ 通过不加趋势
- 互斥：一只股票一个买点类型只有一种标签
- 共振标识附加在标签末尾
