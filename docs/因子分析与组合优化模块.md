# 因子分析与组合优化模块（Alphalens + PyPortfolioOpt）

## 一、模块概述

在现有 CZSC 信号管线（L1→L2→L3→L4→回测）的基础上，新增两个互补模块：

| 模块 | 位置 | 用途 | 核心库 |
|------|------|------|--------|
| **factor_analysis/** | 管道后分析 | 量化评估 L2/L3/L4 因子的预测能力 | Alphalens-Reloaded |
| **portfolio/** | L4→回测之间 | L4 排序后的组合仓位优化 | PyPortfolioOpt |

### 1.1 依赖版本锁定

```
alphalens-reloaded==0.4.6  (要求 pandas <2.4, 与项目 pandas 2.3.3 兼容)
pyportfolioopt==1.6.0       (要求 cvxpy, scipy)
cvxpy==1.9.2
```

## 二、factor_analysis/ — 因子分析模块

### 2.1 因子来源

- **L2**: EntryFilter 各维度原始分（中枢、量比、MACD、底分型、ATR扩张比、ZG站稳天数 等 26 维）
- **L3**: atr_pct, vol_ratio, high_dist, stock_rps, sector_rps
- **L4**: composite, n_l2

### 2.2 核心类

#### FactorExtractor

位置: `factor_analysis/factor_extractor.py`

```python
from factor_analysis import FactorExtractor

extractor = FactorExtractor(regime="CHOP", lookback_days=500)

# 方法 A: 从信号文件直接提取（仅 L2 维度）
factor_df, fwd_returns = extractor.extract(max_stocks=200)

# 方法 B: 从已有的 L4 管道输出提取（含 L3/L4 维度）
factor_df, fwd_returns = extractor.extract_with_l3l4(l4_output_df)
```

#### run_alphalens_analysis

位置: `factor_analysis/alphalens_runner.py`

```python
from factor_analysis import run_alphalens_analysis

# 生成 IC 分析 / 分层收益 / 换手率报告
summaries = run_alphalens_analysis(
    factor_df, fwd_returns,
    periods=(1, 5, 20),
    quantiles=5,
    output_dir="factor_analysis/reports/"
)
```

输出文件:
- `factor_analysis/reports/<因子名>_ic.csv` — 各周期的 IC 均值、IR、分层 spread
- `factor_analysis/reports/_summary.csv` — 所有因子汇总排名

### 2.3 使用场景

1. **因子有效性审计**: 定期跑 `extract` + `run_alphalens_analysis`，查看哪些 L2 维度有真实预测力
2. **权重调优依据**: IC 均值低的维度考虑降权或移出 REGIME_WEIGHTS
3. **L3/L4 因子验证**: 用 `extract_with_l3l4` 验证 composite 评分是否优于单一维度

## 三、portfolio/ — 组合优化模块

### 3.1 核心类

#### PortfolioOptimizer

位置: `portfolio/optimizer.py`

```python
from portfolio import PortfolioOptimizer

# 初始化（默认 HRP）
opt = PortfolioOptimizer(
    lookback=120,        # 协方差估计窗口
    method="hrp",        # hrp | risk_parity | max_sharpe | equal_weight
    max_weight=0.25,     # 单只最大权重
    min_weight=0.02,     # 单只最小权重（低于此剔除）
)

# 在 L4 排序后调用
l4_ranked = l4_ranker.rank(l3_result_df)
weights = opt.optimize(l4_ranked)  # {code: weight}

# 转金额分配
allocations = opt.allocate_capital(weights, total_capital=100_000)
```

### 3.2 优化方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **HRP** (默认) | 层次风险平价，基于距离矩阵聚类后再分配 | A 股板块联动效应强，HRP 对协方差估计误差更稳健 |
| **risk_parity** | 等风险贡献（自实现 SLSQP 优化器） | 预期收益不可靠时的防御性配置 |
| **max_sharpe** | 均值-方差优化，最大化夏普比率 | 需要可靠的预期收益估计（默认用历史均值） |
| **equal_weight** | 等权配置 | 基准对照 / fallback |

### 3.3 与回测的集成

`backtest/runner.py` 新增 `run_all_with_weights()` 函数：

```python
from backtest.runner import run_all_with_weights
from core.metrics import compute_metrics

# 带权重的回测
df = run_all_with_weights(
    code_weights=weights,
    signal_date="2026-07-31"
)
metrics = compute_metrics(df.to_dict("records"), weighted=True)
```

`core/metrics.py` 在 `weighted=True` 时：
- 用 weight 列做加权平均收益率、加权总收益
- 用加权标准差计算 Sharpe
- 未提供 weight 时自动回退到等权

## 四、推荐工作流

```
L1 信号 → L2 EntryFilter → L3 L3Filter → L4 L4Ranker
                                              │
                    ┌─────────────────────────┘
                    ▼
           PortfolioOptimizer.optimize()
                    │
                    ▼
           run_all_with_weights()
                    │
                    ▼
           compute_metrics(weighted=True)
                    │
                    ▼
           FactorExtractor + run_alphalens_analysis  (定期审计)
```

## 五、注意事项

1. **pandas 版本**: Alphalens-Reloaded 要求 pandas <2.4，将项目 pandas 从 3.0.3 降级到 2.3.3
2. **polars 兼容性**: 如果项目中用到 polars，需验证与 pandas 2.3.3 的兼容性
3. **因子提取耗时**: `FactorExtractor.extract()` 每只股票需初始化 EntryFilter（含 CZSC 解析），大规模运行建议分 chunk
4. **协方差估计**: `lookback=120` 在剧烈行情切换时可能不准确，可调整为 60 或 250
5. **单只股票时**: 优化器自动返回 100% 赋权
