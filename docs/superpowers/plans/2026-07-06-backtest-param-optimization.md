# 四级漏斗回测参数调优计划

> **Goal:** 对已实现的 L2/L3 策略进行系统化回测，确定各规则的最优参数组合，并量化每条规则对最终收益的增量贡献。

**Context:** 四级漏斗基本策略已完成（L1 全量沉淀 → L2 策略一区 6 条规则 → L3 策略二区 3 条门禁 + 2 条 P1 → L4 评分）。回测引擎 `backtest.py` 框架已存在，但需要适配当前信号数据结构。

---

## 前置条件：回测引擎适配

当前回测引擎 `backtest.py` 读取 JSON 信号文件中的 `buy_sell_points`，但实际信号数据存储在 Parquet 格式中。需先完成以下适配：

- [ ] **A.1** 将 `load_signals_file()` 从 JSON 改为读 Parquet 信号文件
- [ ] **A.2** 将 `buy_sell_points` 检测改为从 Parquet 信号列的状态变化识别买卖点
  - 买点触发：BUY1/BS2辅助/BS3辅助/三买辅助列中 v1 从非买点→买点
  - 卖点触发：SELL1 列中 v1 从非卖点→一卖
- [ ] **A.3** 验证单股回测能产生交易记录（至少 1 笔）

## 阶段 1：基准回测 — L1→L4 不加 L2/L3 过滤

**目标：** 建立基准绩效，后续所有优化与此对比。

- [ ] **1.1** 改造 `run_all()` 支持指定股票列表（从 `L1_deposition.parquet` 读取）
- [ ] **1.2** 运行全量基准回测，记录指标：

  - 按买点类型（一买/二买/三买）分组统计
- [ ] **1.3** 输出 `data/backtest/baseline_all.parquet` + 指标摘要 JSON

**判定标准：** 基准回测可正常运行，产出可量化的绩效对比基线。

- [ ] **2.4** L2-09 MACD 金叉回测 → 记录增量贡献
- [ ] **2.5** L2-10 MA 多头回测 → 记录增量贡献
- [ ] **2.6** L2-12 力度背驰回测 → 记录增量贡献
- [ ] **2.7** 汇总 L2 单规则贡献表（胜率变化、收益变化、交易量变化）

## 关键决策

1. **回测数据源**：改为从 Parquet 信号文件读取，而非 JSON — 与信号引擎输出一致
2. **回测方法**：基于信号状态变化识别买卖点，保持与 L1→L4 漏斗同类逻辑
3. **优化顺序**：先 L2 门禁 → L2 参数 → L3 门禁 → L4 权重 — 逐层叠加，避免交互效应混淆
4. **过拟合防护**：参数敏感度检查 + 训练/测试时间分割 + OOS/IS 比率
5. **回测注意事项**：czsc 笔计算存在轻微前视偏差（全局数据），回测收益仅供相对比较，不直接等于实盘收益
