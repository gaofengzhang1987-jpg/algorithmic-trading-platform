# 买点入场过滤器设计

## 目标

在 `backtest.py` 的 `simulate_trades` 入场前插入 `EntryFilter`，过滤低质量买点信号，提高买点胜率。

## 架构

```
simulate_trades:
  buy_events → for each buy → EntryFilter.check() →
    ├─ 通过 → ExitEngine → 出场扫描 → 记录交易
    └─ 拒绝 → 跳过
```

`EntryFilter` 是独立类，不改变出场逻辑。

## P0 硬闸门

任一不通过 → 直接拒绝，不进入 P1 评分。

| 规则 | 检查 | 不通过原因 |
|------|------|-----------|
| L2-02 买点类型 | 信号必须含 一买/二买/三买 | "非买卖信号" |
| L2-03 信号新鲜度 | 信号日期距今 ≤30 天 | "信号过期" |

一买+二买同 bar → 同时按两种类型评分，取总分高者。

## P1 六维加权评分

### 评分函数

每维度原生 0-100 分。

**L2-01 笔数得分** (信号值字符串)

| 笔数 | 得分 |
|------|:---:|
| <5 | 0 |
| 5-8 | 20 |
| 9-12 | 50 |
| 13-16 | 75 |
| ≥17 | 100 |

**L2-06 量比得分** (日线 DataFrame)

比值 = 最新成交量 / 20日均量

| 比值 | 得分 |
|------|:---:|
| <0.8 | 20 |
| 0.8-1.2 | 40 |
| 1.2-1.8 | 70 |
| 1.8-3.0 | 100 |
| >3.0 | 50 |

**L2-09 MACD得分** (信号 DataFrame)

检查近5天是否有MACD金叉信号。

| 金叉距今 | 得分 |
|------|:---:|
| ≤3天 | 100 |
| 4-5天 | 60 |
| >5天 | 20 |
| 无金叉 | 0 |

**L2-12 核心验证** (按买点类型不同)

一买 — 力度背驰：当前向下笔.power / 前一同向笔(跳过中枢内).power

| 比值 | 得分 |
|------|:---:|
| <0.3 | 100 |
| 0.3-0.6 | 75 |
| 0.6-0.9 | 40 |
| 0.9-1.0 | 10 |
| ≥1.0 | 0 |

二买 — 回踩深度：回踩笔振幅 / 一买前下跌笔振幅

| 比值 | 得分 |
|------|:---:|
| <0.3 | 100 |
| 0.3-0.5 | 75 |
| 0.5-0.7 | 40 |
| 0.7-1.0 | 10 |
| ≥1.0 | 0 |

三买 — 不参与。

**L2-15 底分型得分** (CZSC对象)

三维评分取均值 sk(0-100) + sc(0-100) + sv(0-100) / 3。

sk — K线结构分：构成分型的K线数
| K线数 | 得分 |
|------|:---:|
| ≥10 | 100 |
| 8-9 | 85 |
| 6-7 | 70 |
| 5 | 55 |
| 4 | 40 |
| 3 | 20 |

sc — 结构质量分

① 强势/弱势判定 (0-60)
| 条件 | 得分 |
|------|:---:|
| 第三根收盘 > 第一根最高价 | 60 |
| 第三根收盘 > 第一根实体中点 + 高开高走 | 45 |
| 第三根收盘 > 第一根实体中点 | 30 |
| 未达到 | 8 |

② BI端点吻合 (0-20)
| 偏差 | 得分 |
|------|:---:|
| ≤0.5% | 20 |
| ≤1.0% | 13 |
| ≤2.0% | 7 |

③ 笔内位置 (0-20)
| 位置比例 | 得分 |
|------|:---:|
| ≥80% | 20 |
| ≥60% | 13 |
| ≥40% | 7 |

sv — 量能确认分 (0-100)

① 分型内缩量 (0-50)：最低点量/分型均量
| 比值 | 得分 |
|------|:---:|
| ≤0.7 | 50 |
| ≤0.85 | 35 |
| ≤1.0 | 20 |
| >1.0 | 5 |

② 右侧放量 (0-50)：右侧均量/左侧均量
| 比值 | 得分 |
|------|:---:|
| ≥2.0 | 50 |
| ≥1.5 | 35 |
| ≥1.2 | 20 |
| ≥1.0 | 10 |

**L2-04 中枢下沿距离** (仅一买)

偏差 = |当前价 - 中枢DD| / 当前价 × 100

| 偏差 | 得分 |
|------|:---:|
| ≤1% | 100 |
| ≤2% | 60 |
| ≤5% | 20 |
| >5% | 0 |

### 门槛

| 买点 | 门槛 | 相当于均分要求 |
|------|:---:|:---:|
| 一买 | 350/600 | 58/100 |
| 二买 | 330/550 | 60/100 |
| 三买 | 280/400 | 70/100 |

## 涉及文件

| 文件 | 操作 |
|------|------|
| `backtest.py` | 新增 `EntryFilter` 类 (复用 zone2_pattern.py 评分函数) |
| `backtest.py` `simulate_trades` | `for buy in buy_events` 前插入 `EntryFilter.check()` |
| `zone2_pattern.py` | 无需修改（EntryFilter 直接 import 评分函数） |

## 不变的部分

- `ExitEngine` — 出场逻辑不变
- `precompute_structure.py` — 结构数据不变（EntryFilter 用 CZSC 对象实时算背驰和底分型）
- `strategy.py` — 不变

## 验证标准

1. `EntryFilter` 单元可独立运行（传参数 → 返回 bool + 分数明细）
2. 3 只测试股票全量跑，对比过滤前后胜率变化
3. 统计各维度得分分布 → 后续调权重用


## 门槛未通过处理

```python
for buy in buy_events:
    result = entry_filter.check(buy)
    if not result.passed:
        continue  # 跳过该信号，不生成交易
    engine = ExitEngine(...)
```

FilterResult 结构:

- passed: bool
- buy_type: str (一买/二买/三买)
- total_score: int
- dimension_scores: dict[str, int]
- reject_reason: str

| 拒绝类型 | reject_reason 示例 |
|---------|-------------------|
| P0 类型 | "非买卖信号" |
| P0 新鲜度 | "信号过期(>30天)" |
| P1 不足 | "P1总分312/350(一买门槛)" |
