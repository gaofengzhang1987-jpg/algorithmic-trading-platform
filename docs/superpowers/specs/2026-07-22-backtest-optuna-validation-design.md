### 实现

三组共用 struct_df 缓存 + CZSC 信号数据。基线 A 回测时需要切到旧版 REGIME_WEIGHTS + REGIME_THRESHOLDS（通过临时 monkey-patch 或独立脚本传参控制），基线 B 和实验组通过修改阈值表实现。一次数据准备，三次过滤+回测循环。

## 三、阈值扫描

（与之前方案相同，未变）

对 6 组（一买/二买/三买 × BEAR/BULL），每组权重固定为 Optuna 标定值，扫下列阈值：

| 组 | 扫描阈值 |
|----|---------|
| 一买 BEAR | [60, 65, 70, 75, 80, 87, 95, 101] |
| 一买 BULL | [97, 109, 117, 122, 129, 135, 144, 151] |
| 二买 BEAR | [164, 168, 178, 182, 187, 191, 196, 201] |
| 二买 BULL | [370, 400, 408, 412, 416, 418, 419, 421] |
| 三买 BEAR | [59, 65, 68, 70, 75, 83, 86, 90] |
| 三买 BULL | [118, 124, 157, 190] |

每组固定权重，计算总分后按不同阈值切割，统计通过信号的 label 分布（Precision / Recall / 通过量）。**不跑回测模拟**——仅用已有 label 做统计。

## 六、不变的部分

- ExitEngine — 不变
- L3/L4 漏斗 — 不涉及
- 出场逻辑（止损/止盈/超时） — 不变

## 七、验证标准

1. 阈值扫描输出与手工选取时的精度-召回数据一致
2. 三组对比：交易笔数/胜率/盈亏比单调变化方向合理
3. 一买 BULL 和三买 BEAR 从禁用→开放后，交易笔数增加、胜率在预期范围内
